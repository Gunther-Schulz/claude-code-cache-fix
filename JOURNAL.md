# claude-code-cache-fix — journal

Incidents and their lessons, dated. One entry per incident: what
happened, and the rule or workflow it justifies.

Registered as the kind `JOURNAL entries` in `.claude/lifecycle.json`,
which declares its six stages. Its staleness rule is CHANGE-COUPLING
and it runs both ways: **a law carrying no journal pointer has no
basis, and a journal entry nothing cites is stale.** Neither is read
against an entry's age.

Created header-only by the wave-1 migration (`lifecycle migrate`), so
that the declaration never names a home that does not exist — an
absent home is the same shape design §3.3 calls BROKEN in a router's
roster. Entries arrive as `docs/dev-loop.md` decomposes in wave 2:
every part of that file sorts into a law, a workflow, a journal entry,
or an audit, and the incident-and-lesson parts land here.
